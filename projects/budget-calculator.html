Budget Calculator

Una app de escritorio para que freelancers y estudios chicos coticen proyectos con un método claro de precios basados en valor, en vez de tirar un número "al ojo".

El problema

Cotizar "a ojo" es uno de los errores más comunes de freelancers que arrancan: subestiman el tiempo real de un proyecto y terminan cobrando menos de lo que deberían.

La solución

Una calculadora de escritorio con una interfaz simple donde el freelancer ingresa el alcance del proyecto y obtiene un precio sugerido basado en valor, con una capa de optimización de tiempos asistida por IA para ajustar la estimación.

Funcionalidades clave

  • Pricing basado en valor — calcula un precio sugerido a partir del alcance y la complejidad, no solo de horas.
  • Optimización de tiempos con IA — ajusta la estimación de horas según el tipo de tarea.
  • Interfaz nativa — construida con CustomTkinter, con diseño responsive dentro de un frame con scroll.
  • Distribución automática — pipeline de CI/CD con GitHub Actions que compila ejecutables para Windows y Linux con cada versión nueva.

Desafíos técnicos resueltos

El layout no se adaptaba bien a distintos tamaños de ventana dentro de un frame scrolleable; se resolvió migrando de .grid() a .pack() dentro del CTkScrollableFrame. Además, se automatizó la generación de releases: cada tag de versión dispara un build que compila el ejecutable con PyInstaller y lo publica como GitHub Release.
